## 확정 결정 (2026-10-08)

| # | 결정 |
|---|---|
| D1 | 좌표는 **행안부 도로명주소 API**(검색 + 좌표제공)로만 얻어 저장한다. SGIS와 카카오 로컬 API는 쓰지 않는다 |
| D2 | **GPS를 쓰지 않는다** |
| D3 | 계획은 **기존 DRAFT 임장**으로 표현한다 |
| D4 | **다녀온 순서**를 기록하고, 나중에 임장 상세에서 지도로 다시 본다 |
| D5 | 임장은 **계획 수립(DRAFT) → 임장 완료(COMPLETED)** 순서로만 진행한다 |
| D6 | **화면에 보이는 매물 순서대로** 경로를 그린다. 실제 걸은 길은 기록하지 않는다 |
| D7 | 완료 뒤 되돌리기는 **최초 완료 시각(`completedAt`)** 으로 처리한다. 한 번 완료한 임장은 다시 "계획"이 되지 않는다 |
| D8 | **추천 순서로 정렬**: 사용자가 주소로 입력한 현재 위치(GPS 아님, 저장 안 함)에서 출발하는 최적 순서를 계산해 화면 순서에 반영한다 |
| D9 | 매물 수정 시 FE가 **위치를 항상 함께 전송**한다. 좌표가 아니라 건물관리번호를 보내고 BE가 좌표를 판정한다 |
| D10 | FE와 BE는 **같은 날 함께 배포**한다(앱 배포 순서 없음, DB SQL은 새 BE 기동 전) |
| D11 | 계획 임장은 "다녀온 임장" 집계에 넣지 않는다. 매물 수 · 최고 관심 매물 · 미완료 요약도 완료 임장 기준이고, 계획은 `plannedVisitCount`로 따로 센다 |
| D12 | 안 간 매물은 1차에서 **삭제 후 완료**한다. `excluded`(「빼고 완료하기」)는 따로 구현한다 |
| D13 | 추천 미리보기의 "현재 위치 → 첫 매물" 구간은 **직선**으로만 그린다 |
| D14 | 지역 행 `plannedVisit`은 **미완료 임장 중 예정일이 가장 이른 1건**이다. FE가 오늘과 비교해 "예정" / "미완료"로 표시한다 |

결정에 따른 최종 구성: **카카오 지도 SDK + 카카오 도보 경로(실시간) + 행안부 도로명주소(저장)**.
생명주기(계획 → 완료)와 경로 순서(화면 순서)에 필요한 BE 보완(`completedAt`, 집계 쿼리 보정, `name` nullable, 위치 컬럼)은 [04 문서](./04-decision-review.md)에 정리했다.
BE 구현은 한 브랜치에서 **커밋 단위(C1~C11)** 로 진행하며, 커밋 계획과 외부 연동 배치는 04 문서 §7.1·§7.2에 있다.

## 초기 조사 결론 (결정 이전)

1. **구현할 수 있다.** 다만 지도 SDK보다 **"좌표를 어디서 얻고 DB에 저장해도 되는가"** 가 가장 큰 제약이다.
   - 카카오 로컬 API, 네이버 Maps API, 브이월드 Geocoder는 **결과 좌표를 DB에 저장하는 것을 약관으로 금지한다.**
     카카오는 2026-08-24 데브톡 답변에서 "사용자가 화면에서 확정하더라도 저장할 수 없다"고 다시 확인했다.
   - 따라서 매물 좌표는 **행정안전부 도로명주소 API와 SGIS 지오코딩 같은 공공 API**로 얻어 저장하는 구조가 안전하다.
     카카오 데이터는 "장소 ID + 실시간 호출"로만 쓴다.
2. **권장 조합**

   | 역할 | 권장 | 저장 |
   |---|---|---|
   | 배경 지도 · 마커 · 경로선 | 카카오맵 JavaScript SDK | — |
   | 주소 검색 → 좌표 | 행안부 도로명주소 검색 API + SGIS 지오코딩(WGS84) | ✅ DB 저장 |
   | 방문 순서 추천 | 자체 구현(FE 또는 BE, 직선거리 기반 TSP 근사) | 계산 결과 저장 가능 |
   | 실제 도보 경로선 · 소요 시간 | **카카오맵 도보 경로 조회 API** (2026-07-21 출시) | ❌ 실시간 호출 |
   | (선택) 지역 사이 대중교통 | 카카오맵 대중교통 경로 조회 API | ❌ 실시간 호출 |

3. **비용:** 개인·소규모 사용이라면 **무료 한도 안에서 운영할 수 있다.**
   카카오 지도 SDK는 하루 30만 건, 도보 경로는 하루 1,000건까지 무료다(첫 번째로 활성화한 앱만 해당).
   초과하면 도보 경로가 건당 10원이다.
4. **법적 리스크:** 사용자 **현재 위치(GPS)를 서버로 보내지 않으면** 위치기반서비스사업 신고 대상에서 벗어날 수 있다.
   1차 범위에서는 출발지를 "역 · 주소 직접 선택"으로 한정할 것을 권한다.
5. **선택하지 않은 공급자**
   - 네이버: 2025-07-01 기존 무료 이용량이 종료됐고, 도보 경로 API가 없으며, 저장 금지 조항도 같다.
   - 구글: 2026-02-27 지도 반출이 조건부로 승인됐지만 국내 도보 길안내 제공 현황이 불확실하고 국내 POI 품질도 낮다.
   - TMAP: 도보 경로를 무료로 하루 1,000건 제공하는 대안이다. 다만 카카오 지도 위에 TMAP 경로를 그리면 도로 데이터가 어긋날 수 있고, 타사 지도와 섞어 쓰는 것에 대한 약관이 불명확하다. **예비 공급자**로 둔다.
   - ODsay: 무료 Basic의 한도 표기가 30건과 1,000건으로 서로 다르고, 카카오 대중교통 API와 기능이 겹친다.
